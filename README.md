# Алексей Тарануха — сайт-визитка

Одностраничный сайт: трейдинг по золоту и серебру (XAUUSD / XAGUSD),
агентство digital-услуг и канал в Telegram.

**Живая версия:** https://azbyka009.github.io/

## Что внутри

- `index.html` — весь сайт одним файлом: разметка, стили и скрипты вместе,
  фотографии вшиты прямо в код. Никакой сборки и зависимостей не нужно.

## Как открыть локально

Просто открыть `index.html` в браузере.

## Как править

Текст и структура — в конце файла, стили — в блоке `<style>` сверху.
Ссылки на Telegram лежат в атрибутах `href`.
